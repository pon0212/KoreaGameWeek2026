# Taste Passport background music

`TastePassportTheme.wav` is an original, locally synthesized 32-second travel score created for this MVP. It combines a brisk major-key arpeggio, warm chord bed, bass pulse and plucked upper melody for a lightly dramatic, classical-adventure feel. It uses no external recording, sample, or Internet source. It is temporary prototype music; replace it with commissioned or otherwise cleared final music before release.

Unity import uses mono Vorbis compression in memory. The game falls back to its generated chapter tones and writes a clear warning if this clip is missing.
