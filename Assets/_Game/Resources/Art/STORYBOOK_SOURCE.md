# Storybook art provenance

`StorybookClosed.png` and `StorybookOpen.png` were generated specifically for Taste Passport on 2026-11-05 with OpenAI image generation. They are original game illustrations. The user's watermarked stock image was used only as a loose reference for an aged leather book silhouette and was not copied into the project.

- Closed sprite prompt: Original transparent game sprite of a closed, aged warm-brown leather travel book in three-quarter view, with embossed travel motifs and a thick cream page block. No text, watermark, checkerboard, or environment.
- Open sprite prompt: Matching front-facing portrait leather book in its open state, with a large blank parchment page for Unity text overlays. No text, watermark, checkerboard, or environment.

These are current production-candidate illustrations. Visual placement and typography still require a licensed Unity Play Mode review at phone resolutions before release.
